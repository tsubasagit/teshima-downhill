# 豊島ダウンヒル 🛹

香川県・豊島（てしま）の坂道を、スケートボードで海までかけ下りる 3D ゲームです。
CoderDojo の教材としてつくりました。**コードを書きかえて、自分だけのコースにできます。**

👉 **[いますぐ遊ぶ](https://tsubasagit.github.io/teshima-downhill/)**

## あそびかた

| そうさ | やりかた |
|---|---|
| 左へ | ← キー、または画面の左半分をタップ |
| 右へ | → キー、または画面の右半分をタップ |

- 🍋 レモンをあつめると スコアが上がります
- 🚚 軽トラや島バスにぶつかると ライフがへります（3つまで）
- 🚢 港に着いたらゴール。何周でも走れて、周をかさねると すこしずつ速くなります

## 自分のパソコンで動かす

インストールは必要ありません。ブラウザだけで動きます。

1. このリポジトリを [ダウンロード](../../archive/refs/heads/main.zip) して、 zip を展開する
2. `start-game.cmd` をダブルクリックする（Windows）
3. ブラウザが開いて、ゲームがはじまります

> Mac / Linux のときは、フォルダの中で `python3 -m http.server 8940` を実行して、
> ブラウザで `http://127.0.0.1:8940/index.html` を開いてください。
>
> `index.html` を直接ひらくと、ブラウザの制限で画像が読みこめません。かならずサーバー経由で開いてください。

## ★ 改造してみよう

`game.js` をテキストエディタで開くと、いちばん上に2つの「かえてみよう」があります。
数字を書きかえて保存し、ブラウザを更新するだけで、すぐ変わります。

### 1. CONFIG — 速さや色をかえる

```js
const CONFIG = {
  speed: 42,             // 前にすすむ速さ（大きくすると速くなる）
  lives: 3,              // ライフの数
  obstacleDensity: 0.32, // 障害物の出やすさ（0〜1）
  jacketColor: 0x4aa8e8, // パーカーの色
  boardColor: 0xe07a2e,  // スケボーの色
  ...
};
```

### 2. COURSE — 自分だけの坂道をつくる

```js
const COURSE = [
  { curve: 0,   length: 88,  slope: 0.05 },  // curve: 曲がる角度（＋で右、－で左）
  { curve: 96,  length: 232, slope: 0.30, bigCurve: true },  // length: その区間の長さ
  ...                                         // slope: 坂のきつさ
];
```

- `curve` を ぜんぶ `0` にすると、まっすぐな坂になります
- `bigCurve: true` をつけると、その手前に「速度落せ」の路面文字と標識が自動で立ちます
- `slope` を大きくすると、その区間だけ急な坂になります

### 3. あたらしいルールを足す

`game.js` の「6. 当たり判定」の中に、ぶつかったとき・アイテムを取ったときの
しょりが書いてあります。ここに新しいルールを足せます。

### 絵をかえる

`assets/` の中の画像を、**同じファイル名**で上書きすると絵が変わります。
どんな絵をつくればいいかは [assets/README.md](assets/README.md) に書いてあります。

画像は配信を軽くするため、透過なしを `.jpg`、透過ありを `.webp` にしてあります（合計 7.2MB）。
PNG から作りなおすときは `assets-original/` に置いて `python tools/optimize_assets.py` を実行してください。

## 中身の構成

| ファイル | なかみ |
|---|---|
| `index.html` | 画面の枠と、HUD・スタート画面などの HTML |
| `styles.css` | 見ための設定 |
| `game.js` | ゲーム本体（CONFIG / COURSE / 風景 / プレイヤー / 当たり判定 / ゲームループ） |
| `assets/` | 空・海・道路・キャラクターなどの画像 |
| `start-game.cmd` | ローカルサーバーを立ててブラウザを開く（Windows） |

3D の描画には [three.js](https://threejs.org/) r128 を CDN から読みこんでいます。
ビルドの手順はなく、ファイルを保存してブラウザを更新すればすぐ反映されます。
