## 画像形式について（2026-08-17 最適化）

配信を軽くするため、元の PNG（合計 73MB）を次の形式に変換してあります（**合計 7.2MB / 1割**）。

| 種類 | 形式 | 理由 |
|---|---|---|
| 透過なし（空・海・道路・地面・石垣・お店） | `.jpg` | どのブラウザでも確実に表示できる |
| 透過あり（キャラクター・草・木・雲・障害物） | `.webp` | 透過を保ったまま PNG の 1/4〜1/5 になる |

- くりかえして貼るタイルは **1024x1024 ちょうど**（2のべき乗）にそろえてあります。
  こうしないと three.js が実行時に拡大縮小するので、そのぶん重くなります
- 元の PNG は `assets-original/`（Git には入れていません）に残してあります
- 画像を作りなおしたら、`assets-original/` に PNG を置いて
  `python tools/optimize_assets.py` を実行すると `assets/` が更新されます
